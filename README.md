## 🛠️ Requirements

Before running the code, make sure you have:

* Node.js
* npm
* TypeScript

Check the installations:

```bash
node --version
npm --version
tsc --version
```

## 🚀 Running TypeScript

Compile a TypeScript file:

```bash
tsc filename.ts
```

Then run the generated JavaScript:

```bash
node filename.js
```

Or use TypeScript directly with a suitable development setup.
